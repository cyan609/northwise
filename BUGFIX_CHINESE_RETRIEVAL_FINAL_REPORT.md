## 1. Confirmed Root Cause

The refusal message "目前中文檢索僅支援以下主題詞：噪音、生態、水質、廢物、景觀、文化遺產。請使用上述詞語，或以英文提問。" was generated by a single code path in `app.py` (line 587).

**Trigger conditions:**
1. `detect_lang(question)` returns `"zh-Hant"` (CJK characters found)
2. `_map_chinese_terms(question)` returns `None` (no Chinese topic phrases matched)
3. `CORPUS.gate(question)` returns `empty_query` or `all_oov` (no English tokens extracted)
4. `_lookup_glossary(question)` returns `None` (no glossary match)

**The root cause:** `_TC_TOPIC_MAP` contained only 11 Chinese phrases. Any Chinese question that didn't contain one of these exact phrases AND didn't contain any English technical terms was refused.

This was overly restrictive. Queries like:
- `哪些村落會受到這個發展項目影響？` (Which villages will be affected?)
- `這份環評報告如何評估水文影響？` (How does this EIA assess hydrological impact?)
- `請解釋這份報告的主要環境影響。` (Explain the main environmental impacts.)

...were all valid EIA-related questions but were refused because they didn't match the 11 hardcoded phrases.

## 2. Files Changed

**`app.py`** — One change:

Expanded `_TC_TOPIC_MAP` from 11 phrases to **52 phrases**, covering:
- Water & hydrology (水文, 水質, 排水, 污水, 雨水, 河流, 渠道)
- Noise (噪音, 噪音屏障, 聲音)
- Ecology (生態, 魚類, 生境, 物種, 植被, 濕地, 林地, 農地, etc.)
- Waste (廢物, 廢物管理)
- Cultural heritage (文化遺產, 風水, 考古)
- Landscape (景觀, 視覺影響)
- Air quality (空氣質素, 空氣污染, 污染, 粉塵, 臭氣)
- Traffic (交通, 運輸, 道路, 車輛)
- Construction (施工, 工地, 建築, 建造)
- Community/socio-economic (村落, 居民, 人口, 社會, 經濟, 健康, 安全, 風險)
- EIA process (環評, 環境影響, 評估, 報告, 緩解措施, 監測, 基線, 累積, 殘餘, 替代方案, 敏感度, 敏感受體)
- General EIA (發展項目)

**Deliberately excluded** overly generic terms that would match non-EIA questions:
- `項目` (project) — would match any project question
- `發展` (development) — too broad
- `土地` (land) — too broad
- `規劃` (planning) — too broad
- `設計` (design) — too broad

All mapped English terms were verified to exist in the corpus vocabulary.

## 7. Remaining Limitations

1. **`_TC_TOPIC_MAP` is still a hardcoded list.** While now much more comprehensive (52 phrases), it cannot cover every possible Chinese EIA question. Questions with novel phrasing may still be refused if they don't match any phrase and don't contain English technical terms.

2. **`detect_lang()` is a simple CJK check.** Questions with zero CJK characters are classified as English even on a zh-Hant interface.

3. **Synthesis (Ollama) language is not reliably controlled.** The LLM may respond in English even when `lang="zh-Hant"`.

4. **No thumbnail generation.** Evidence items lack `thumbnail_url`.

5. **"What is quantum foam?" returns evidence.** The English BM25 gate accepts "quantum" and "foam" as valid tokens (they exist in corpus vocabulary in other contexts). This is expected BM25 behaviour — the gate validates token presence, not semantic relevance.
