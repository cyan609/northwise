## Known gaps after this batch

1. **Figure/table text interleaving is unmeasured.** PDFKit returns text in
   content-stream order, so table cells can interleave with prose. Harmless
   for folios, material for retrieval. Must be sampled before Q&A.
2. **Chunking has not been designed against this corpus.** Page-level chunks
   are the approved starting point, but page sizes vary widely (the sign page
   has no text at all; ch.10 pages run to ~3.4k characters).
3. **`reports.json` remains `validation_status: incomplete`** — report-area
   geometry is still deferred, unrelated to extraction.
4. **No index, no retrieval, no Q&A exists yet.** This inventory covers
   extraction only.
