# NORTHWISE Core Northern Metropolis (core_nm) EIA Registry Expansion Report

## Scope
This report documents the revised NORTHWISE EIA Registry expansion scope for **Category A: `core_nm`** — core Northern Metropolis projects only.

### Inclusion Rule
A report is included only when reliable official evidence establishes that the project is explicitly part of, or located within, a Northern Metropolis development area.

### Exclusions
- `related_nm` infrastructure projects merely connected to Northern Metropolis
- `cumulative_reference` neighbouring projects
- Projects included solely because they mention Northern New Territories or the Northern Metropolis
- Candidates whose relationship to a designated Northern Metropolis development area cannot be established

## Evidence Used

1. **EPD EIA Register**: Full search of all 324 EIA reports (pages 1-33) at [epd.gov.hk/eia/en/register](https://www.epd.gov.hk/eia/en/register)
2. **Northern Metropolis Official Website**: Four zones and sub-areas from [nm.gov.hk/en/four-zones](https://www.nm.gov.hk/en/four-zones)
3. **Project Titles**: Direct name matching against NM zone area names

---

## Limitations

1. **Title-based matching**: Inclusion is based on project titles matching NM zone area names. Actual report content was not verified.
2. **Pre-dated projects**: Some projects (1998-2000) pre-date the Northern Metropolis concept (announced 2021). These are flagged.
3. **Infrastructure ambiguity**: Drainage, sewage, road, and railway projects in NM areas may be supporting infrastructure rather than core development.
4. **Indicative boundaries**: The nm.gov.hk zone boundaries are marked as "indicative only."
5. **Under consideration**: Two projects (EIA-325/2026, EIA-324/2026) are still under consideration and have no register number.
6. **Register completeness**: This inventory covers the EPD EIA register only. Projects in planning or under other approval mechanisms are not included.

---

## Recommendations

1. **Import verified core_nm projects**: The 8 verified projects should be added to the NORTHWISE registry.
2. **Review candidates**: The 20 review-needed candidates should be evaluated against a stricter definition of `core_nm` (e.g., "major land development or strategic infrastructure explicitly named in NM planning documents").
3. **Verify project content**: For high-priority candidates, verify the actual EIA report content confirms the project is within NM boundaries.
4. **Do not import unverified candidates**: Keep review-needed candidates in the separate inventory file until verified.
